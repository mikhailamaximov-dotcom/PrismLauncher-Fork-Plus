# 🚀 PrismLauncher-Fork-Plus

An open-source, community-driven fork of **Prism Launcher** built with **C++** and **Qt**, designed with full support for offline/cracked accounts, enhanced features, and custom flexibility.

---

### 🤝 Join the Development Team!

We are actively looking for contributors to help bring this project to life:
* **C++ / Qt Developers:** Help us implement launcher logic, polish the UI, and improve cross-platform performance.
* **Web Developers:** Build the project website and integrate an automated split-donation system for revshare.
